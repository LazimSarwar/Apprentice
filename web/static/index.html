    How it works

    Each stage is separate and checkable — every verdict points back to something the tracker actually saw.

    Reference
    One good video
    Anyone records the procedure done right, on a phone.
    Understand
    Ordered steps
    Muse Spark reads each step and its result. Also runs on the open-weight Muse Spark Open.
    Evidence
    Every object tracked
    SAM 3.1 follows each object frame by frame, so each step is backed by what was seen.
    Compare
    When did each step happen?
    Each step is located in time in the attempt; a temporal check catches skips, swaps and wrong places.
    Demo clips are generated test videos; the robot is a simulated Franka Panda (MuJoCo). Verdicts and rates come straight from the pipeline and include every failure.
